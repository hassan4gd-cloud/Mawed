# تطبيق «موعد» — Android

شارك أي رسالة فيها موعد (واتساب، تلغرام، البريد…) مع تطبيق **موعد**، فيستخرج منها التاريخ والوقت وعنوان الموعد تلقائياً، ثم:

- ينبّهك **قبل الموعد بعشر دقائق** (يمكن تغييرها إلى 5 / 15 / 30 دقيقة أو ساعة) **برنين بملء الشاشة مثل المنبّه** — نغمة واهتزاز يتكرران حتى تضغط «إيقاف» (يتوقف وحده بعد 5 دقائق). ويمكن اختيار «إشعار عادي» بدلاً منه لكل موعد.
- **يحذف الموعد تلقائياً** عند انتهاء وقته.
- التاريخ والوقت يُستخرجان **داخل الهاتف بدون إنترنت**، والمواعيد محفوظة داخل الهاتف فقط.
- **عنوان الموعد بالذكاء الاصطناعي (Google Gemini)** اختياري: أضف مفتاحاً مجانياً من الإعدادات. بدون مفتاح أو إنترنت يُستخدم العنوان المحلي.

## طريقة الاستخدام

1. في واتساب/تلغرام/البريد: اضغط مطولاً على الرسالة ← **مشاركة** ← اختر **موعد**.
   أو حدّد جزءاً من النص ← من قائمة التحديد اختر **أضف إلى موعد**.
   أو انسخ الرسالة، افتح التطبيق ← **موعد جديد** ← **لصق**.
2. تظهر شاشة المراجعة وفيها العنوان والتاريخ والوقت المستخرجة — عدّل ما تريد.
3. اضغط **حفظ الموعد**.

## بناء ملف APK

### الطريقة 1: GitHub (بدون تثبيت أي برنامج)
1. أنشئ مستودعاً جديداً على github.com وارفع محتويات هذا المجلد كما هي (بما فيها مجلد `.github`).
2. افتح تبويب **Actions** ← سيبدأ «Build APK» تلقائياً (3–5 دقائق).
3. عند انتهائه افتح التشغيل ← من **Artifacts** نزّل **Mawid-APK** ← فك الضغط وانقل `app-debug.apk` إلى الهاتف وثبّته.

### الطريقة 2: Android Studio
1. افتح المجلد في Android Studio (File ← Open).
2. انتظر انتهاء المزامنة، ثم: Build ← Build App Bundle(s) / APK(s) ← Build APK(s).
3. الملف يكون في `app/build/outputs/apk/debug/app-debug.apk`.

عند التثبيت سيطلب الهاتف السماح بـ«تثبيت تطبيقات من مصادر غير معروفة» — وافق لهذه المرة.

## ملاحظات مهمة على الهاتف

- **اسمح بالإشعارات** عند أول تشغيل، وإلا لن يظهر التذكير.
- في Android 14 فما فوق: إذا ظهر في التطبيق شريط «الإشعارات بملء الشاشة» اضغطه وفعّل الخيار، ليظهر التنبيه كشاشة كاملة.
- النغمة المستخدمة هي نغمة المنبّه الافتراضية في هاتفك، وترتفع حسب «مستوى صوت المنبّه».
- في هواتف Xiaomi / Huawei / Oppo / Samsung قد يوقف نظام توفير البطارية التذكيرات:
  الإعدادات ← التطبيقات ← موعد ← البطارية ← **بلا قيود** (وفعّل «التشغيل التلقائي» إن وُجد).
- يعمل على Android 8.0 فما فوق.

```
  SmartParser.java        محلّل الرسائل (عربي/إنجليزي، بدون إنترنت)
  EditorActivity.java     شاشة استقبال المشاركة ومراجعة الموعد
  MainActivity.java       قائمة المواعيد القادمة
  AlarmScheduler.java     جدولة التذكير والحذف التلقائي
  AlarmReceiver.java      تنفيذ التذكير/الحذف عند حلول الوقت
  BootReceiver.java       إعادة الجدولة بعد إعادة تشغيل الهاتف
  NotificationHelper.java الإشعارات
  AppointmentStore.java   الحفظ داخل الهاتف
app/src/test/.../SmartParserTest.java  اختبارات المحلّل
```
